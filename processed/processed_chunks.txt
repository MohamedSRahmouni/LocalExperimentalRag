Chunking Strategies
Chunking splits documents into smaller pieces for retrieval. Fixed-size chunking uses equal lengths
but may break context. Semantic chunking splits by meaning (sentences/paragraphs), preserving
coherence. Recursive chunking combines both by splitting hierarchically. Choose chunk size based
on embedding context window, domain structure, and retrieval quality trade-off.
Embedding Models
Embedding models convert text into dense vectors capturing semantic meaning. They map similar
texts to nearby points in vector space using neural networks trained on large corpora.
Choosing Embedding Models
Consider domain match, multilingual support, latency, cost, and benchmark performance (MTEB).
Use domain-specific embeddings when available.

enables multi-step reasoning and dynamic retrieval.

Hybrid Search
Hybrid search combines vector similarity and keyword (BM25) search. It improves recall by
capturing both semantic and lexical matches.
Re-ranking

improving precision.
Multi-hop Questions

Lost in the Middle
LLMs tend to ignore middle context in long inputs. Mitigate via reordering, chunk prioritization, and
windowing.
Evaluation
Faithfulness: answer grounded in sources. Relevance: retrieved docs match query. Context
precision/recall: quality of retrieved chunks.
Self-RAG
Self-RAG allows the model to decide when to retrieve using confidence or uncertainty signals.
Graph RAG
Graph RAG uses knowledge graphs for structured relationships. Useful for complex multi-hop
reasoning.
Structured Data
Use SQL querying, table-aware embeddings, or tools to query structured sources directly.
Failure Modes
Hallucination, poor retrieval, redundancy, latency. Debug via logging, eval datasets, and ablations.
Freshness
Use incremental indexing, streaming pipelines, and document versioning.
Latency Optimization

Chunking Strategies
Chunking splits documents into smaller pieces for retrieval. Fixed-size chunking uses equal lengths
but may break context. Semantic chunking splits by meaning (sentences/paragraphs), preserving
coherence. Recursive chunking combines both by splitting hierarchically. Choose chunk size based
on embedding context window, domain structure, and retrieval quality trade-off.

Lost in the Middle
LLMs tend to ignore middle context in long inputs. Mitigate via reordering, chunk prioritization, and
windowing.
Evaluation

precision/recall: quality of retrieved chunks.
